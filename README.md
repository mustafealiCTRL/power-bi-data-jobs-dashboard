# Power BI Data Jobs Dashboard

![Dashboard Preview](dashboard-preview.png)

## Project Overview

This is a guided Power BI project completed while following Luke Barousse's Power BI for Data Analytics course.

The project uses job-market data to explore job demand, salary information and the geographic distribution of data roles. I completed the project to develop practical experience using Power BI to turn raw data into a clear and interactive report.

## Dashboard Features

- KPI cards displaying job count and salary metrics
- Comparison of job roles and salary information
- Geographic visualisation of job opportunities
- Interactive filtering and report navigation
- Clear dashboard layout designed to communicate key information quickly

## Skills Demonstrated

- Power BI Desktop
- Data visualisation
- KPI reporting
- Dashboard design
- Data filtering
- Analytical thinking
- Presenting data clearly for decision-making
